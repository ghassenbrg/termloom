# Changelog

## 0.1.0 - 2026-09-12

- Initial workbench with explorer/editor, Git, interactive PTYs, local agent
  sessions, responsive keyboard/mouse UI, and persistence.
- Generic LSP and DAP clients with real rust-analyzer and lldb-dap validation.
- Safe local VSIX management, capability reports, language associations,
  snippets, themes, and explicit unsupported Extension Host UI.
- Optional Herdr agent discovery/control adapter and thin launcher plugin.
